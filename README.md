# taste-quest

A Pokemon Go-style taste explorer powered by the [Qloo](https://www.qloo.com) Taste AI API, built for the [Qloo Agentic Hackathon](https://qloo.devpost.com/) (2026).

Pick your tastes, say how much time you have, and get a walkable route on a live map, ranked by Qloo place affinity. Each stop explains why it fits you, and the route updates as you walk. Built for travelers and digital nomads. You can also explore with friends using group taste overlap.

**Stack:** Next.js on Vercel, MapLibre GL, walking directions, Vercel AI SDK agent, Qloo Insights API.

**Status:** in development. Setup instructions will be added as the build lands.
